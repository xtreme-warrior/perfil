//Lo que construyo

Apps multiplataforma para formatos de campo, donde la señal, la ubicación y la seguridad importan.

  • Modo offline

    Los formatos de campo se siguen llenando aunque no haya señal.

  • Geocercas y georreferenciación

    La app sabe cuándo el usuario entra o sale de una zona.

  • Fotos y videos con GPS

    Cada captura guarda la ubicación donde se tomó.

  • Escaneo OMR

    Lee las marcas de un formato a partir de una imagen.

  • Bloqueo de capturas

    Protege el contenido impidiendo capturas de pantalla.

  • Notificaciones

  • Cámara

  • Juegos

    También desarrollo juegos móviles.
